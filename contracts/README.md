# contracts: 파트 사이의 약속

> 상태: v0 작성 전 (메모 수준 초안) · 담당: 전원 · 최종 수정: 2026-11-06 · AI/Claude

## 계약이란

FE, BE, AI가 서로 주고받는 데이터의 모양과 요청 창구(API)를 미리 정해둔 약속이다.
계약이 있으면 세 명이 서로를 기다리지 않고 동시에 개발할 수 있다. 각자 샘플 데이터로 일하다가 나중에 합치면 맞물린다.

| [api.md](api.md) | FE와 BE 사이의 요청 창구 목록 | BE | FE |

## 진행 방법

1. 지금은 md로 말로 정리한 메모 수준이다. 필드 이름도 전부 바뀔 수 있다.
2. 기술 스택이 정해지면, 각자 에이전트와 논의한 내용을 제안서로 모아 **v0**을 확정한다.
3. v0이 확정되면 그 내용을 기계가 읽는 형식(예: JSON Schema, OpenAPI)으로도 만든다. 어떤 형식을 쓸지는 스택에 따라 정한다.
4. 확정 이후 변경: 제안서 → 팀장 결정 → 버전을 올리고 아래 변경 기록에 적는다.
