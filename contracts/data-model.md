# 데이터 모양 (메모 초안)

> 상태: 초안 · 담당: BE (설계도 부분은 AI) · 최종 수정: 2026-11-06 · AI/Claude

이름과 항목은 전부 바뀔 수 있다. 영어 이름은 나중에 코드에서 쓸 후보다.

## 전체 관계

- **강의(Lecture)** 하나에 **페이지(Page)** 여러 개
- 강의 하나에 모드별 **분할 계획(Outline)**
- 분할 계획 하나에 **클립 계획(ClipPlan)** 여러 개
- 클립 계획 하나에 생성된 **클립(Clip)** 하나 (2단계에서 다시 만들면 여러 버전)
- 클립 하나에 **영상 설계도(Blueprint)** 하나와 음성
- 오래 걸리는 처리는 모두 **작업(Job)**으로 추적

## 강의 (Lecture)

| 항목 | 후보 이름 | 설명 |
|---|---|---|
| 번호 | id | |
| 제목 | title | 파일 이름이나 첫 페이지에서 |
| 페이지 수 | pageCount | |
| 올린 시각 | createdAt | |
| 상태 | status | 업로드됨 / 분석중 / 준비됨 / 실패 |

## 페이지 (Page)

| 항목 | 후보 이름 | 설명 |
|---|---|---|
| 페이지 번호 | number | 1부터 시작할지 0부터 시작할지 정해야 한다 |
| 글자 | text | 추출한 글자 |
| 그림 주소 | imageUrl | 옆 패널에 띄울 원본 페이지 그림 |

|---|---|---|

| 순서 | order | 피드에 나오는 순서 |

## 영상 설계도 (Blueprint) · 담당 AI, 검토 FE

자세한 개념은 [docs/04](../docs/04-video-blueprint.md)에 있다. 형식 v0은 미정이다(Q-AI-09).

| 항목 | 후보 이름 | 설명 |
|---|---|---|
| 테마 | theme | 어두움 / 밝음 (Q-AI-06) |
| 장면 목록 | scenes | |
| 장면: 내레이션 문장들 | scenes[].lines | |
| 장면: 부품 목록 | scenes[].elements | 부품 종류, 위치, 내용 |
| 장면: 동작 목록 | scenes[].actions | 어느 문장에서 어떤 부품이 무엇을 하는지 |
| 장면: 근거 페이지 | scenes[].sourcePages | |

주의: AI가 형식을 확실히 지키도록 구조를 평평하고 단순하게 유지한다. 부품 안에 부품을 계속 넣는 식의 재귀 구조는 쓰지 않는다.

## 작업 (Job)

| 항목 | 후보 이름 | 설명 |
|---|---|---|
| 번호 | id | |
| 종류 | type | 분석 / 클립 생성 / 다시 만들기 |
| 상태 | status | 대기 / 진행중 / 완료 / 실패 |
| 진행률 | progress | 예: 15개 중 4개 완료 |
| 오류 | error | 실패 이유 (사용자에게 보여줄 문장) |
