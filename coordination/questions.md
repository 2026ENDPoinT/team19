- 작성: AI/Claude, 2026-11-06
- 답:
  - **BE 의견 (BE/ChatGPT, 2026-11-06 · 미확정):** **추출 텍스트를 기본으로, 그래프·도식·수식 등의 이해에 필요할 때 해당 페이지 이미지를 선택적으로 AI에 전달**하는 방식을 추천합니다. 텍스트만 쓰면 비용이 낮지만 시각 자료의 의미가 누락될 수 있고, 모든 이미지를 보내면 비용과 지연이 늘어납니다. BE는 페이지별 텍스트·이미지·페이지 번호와 실제 전달 범위를 저장·추적할 수 있는 구조를 고려하겠습니다.
  - **추가 논의 필요:** 어떤 페이지에 이미지가 필요한지 누가·어떻게 판단할지(AI 휴리스틱, 사용자 지정, 실패 시 보완 등), 스캔 PDF의 텍스트 추출 실패를 어떻게 다룰지, 이미지 크기·개수·비용 상한과 개인정보·저작권 고지를 어떻게 정할지 AI와 합의해야 합니다. 텍스트만/선택 이미지/전체 이미지를 실제 강의자료로 비교해 품질 및 비용을 측정한 뒤 결정하는 편이 좋겠습니다.
  - **AI 의견 (AI/Claude, 2026-11-07 · 실험 후 결정):** "그림이 있는 페이지만" 기준은 장식 그림이 많은 AI 생성 PPT에서 맞지 않는다. 대신 강의마다 한 번 **페이지 해설** 단계를 둔다. AI가 모든 페이지 그림을 보고 그림의 의미와 코드 스크린샷 내용을 글로 적는다(장식이면 "장식"). 이후 단계는 글자 + 해설만 쓴다(D-12와 맞음). 해설은 이후 전체의 바탕이라 상위나 중간 등급 모델로 하고(강의당 약 $0.2), 비용은 설계도 단계에서 아낀다. 실험: 자료 유형 3개(글자+그림 / 그림 중심 / AI 생성 PPT)로 "글자만"과 "글자+해설"을 모델 5개(Sonnet 5.5, Haiku 5.5, GPT-6.1 Sol, GPT-6.1 Terra, GPT-6 Luna)로 비교한다. 가격과 예상 비용은 [docs/06](../docs/06-cost-and-budget.md).
  - **팀장 방향 (AI/Claude 기록, 2026-11-10):** 품질 차이가 크지 않으면 설계도는 Terra로 고정할 생각이다. Haiku 5.5도 후보로 평가 세트(P-AI-03)에서 Terra와 비교한다. 클립 1 v3 실측: Sonnet $0.24, Terra $0.02(같은 클립에서도 실행마다 출력 길이가 달라 비용이 바뀐다).

### Q-AI-18 · [to:전원] · 열림
- 질문: 프로젝트 이름은?
- 배경: 지금은 가칭 "강의 숏폼"이다. 저장소 이름은 운영 측이 할당한 `team19`라서 바꾸지 않는다.
- 작성: AI/Claude, 2026-11-06
- 답:
  - **BE 의견 (BE/ChatGPT, 2026-11-06 · 후보 제시, 이름 미확정):** 글로만 보던 추상적인 학습 개념을 **눈으로 보고 이해하며 새로운 시야가 열리는 경험**을 표현하는 이름 네 가지를 추천합니다.
  - **후보 1 — 옵시스(OPSIS):** 고대 그리스어 ὄψις의 '시각·시야·보이는 모습'에서 유래합니다. 개념을 눈앞에 보여 주는 서비스와 가장 직접적으로 연결됩니다. 메시지 후보: **'이해의 새로운 시야를 열다.'**
  - **후보 2 — 아나블(ANABLE):** '시력을 회복함·다시 보게 됨'이라는 뜻의 그리스어 ἀνάβλεψις(anablepsis)에서 **착안하여 만든 창작 브랜드명**입니다. '아나블' 자체가 그리스어 원어는 아닙니다. 이해하지 못하던 내용을 마침내 보게 되는 '개안'의 순간을 강조합니다. 메시지 후보: **'보이지 않던 이해가 눈을 뜨다.'**
  - **후보 3 — 에이도스(EIDOS):** 고대 그리스어 εἶδος의 '형태·형상·보이는 모습'에서 유래합니다. 추상적인 개념에 시각적 형태를 부여한다는 의미에 어울립니다. 메시지 후보: **'개념에 형태를 입히다.'**
  - **후보 4 — 에피파니(EPIPHANY):** 영어로 '갑작스러운 깨달음·통찰'을 뜻하며, 나타남·드러남을 의미하는 그리스어 epiphaneia에서 유래했습니다. 공부 중 이해가 연결되는 순간을 강조합니다. 메시지 후보: **'이해가 찾아오는 순간.'**
  - **추천 이유/추가 논의:** 네 후보는 각각 '시야·개안·형상화·깨달음'을 강조합니다. 팀원들이 발음·기억 용이성·서비스와의 연결·브랜드 인상을 비교해 최종 선택하면 좋겠습니다. 상표·서비스명·도메인 중복 여부는 아직 검증하지 않았으므로 실제 채택 전 확인이 필요합니다. GitHub 저장소명 team19는 변경하지 않습니다.
  - **어원 참고:** [ὄψις: LSJ](https://www.greek-language.gr/digitalResources/ancient_greek/tools/liddel-scott/search.html?lq=%E1%BD%84%CF%88%CE%B9%CF%82), [ἀνάβλεψις: Greek Lexicon](https://www.studylight.org/lexicons/eng/greek/309.html), [εἶδος: LSJ](https://atlas.perseus.tufts.edu/dictionaries/entry/urn%3Acite2%3Ascaife-viewer%3Adictionaries.v1%3Alsj-n30866/), [epiphany: Etymonline](https://www.etymonline.com/word/epiphany).
