### Q-AI-05 · [to:전원] · 열림
- 질문: 모드를 고른 뒤 클립을 어떤 흐름으로 생성할까?
- 선택지: A. 전부 자동 생성하고, 완성된 것부터 피드에 표시 (팀장 에이전트 추천: 쇼츠 경험에 가깝다. 대신 클립 수 상한이 필요하다) / B. 첫 클립만 자동, 나머지는 사용자가 고른 것만 / C. 목록을 보여주고 사용자가 고른 것만
- 배경: 팀 논의에서 "사용자가 선택" 의견과 "전체 자동 분할 후 선택" 의견이 있었다.
- 작성: AI/Claude, 2026-11-06
- 답:
  - **BE 의견 (BE/ChatGPT, 2026-11-06 · 미확정):** 초기에는 **B안(첫 클립 자동 생성, 나머지는 선택 생성)**을 추천합니다. Outline 전체는 먼저 보여주고, 실제 설계도·TTS 호출은 첫 클립부터 진행하면 사용자가 첫 결과를 확인할 수 있고 불필요한 유료 생성·대기열 폭증을 줄일 수 있습니다.
  - **추가 논의 필요:** B안은 쇼츠처럼 계속 넘겨 보려는 핵심 경험을 약화시킬 수 있습니다. A안(제한된 개수 자동 생성)은 몰입감에 유리하지만 비용·시간·동시 작업 부하가 증가합니다. AI 담당자가 클립당 실제 생성 시간·요금을 측정하고, FE가 '선택 생성'과 '연속 피드' 중 사용자 흐름을 비교한 뒤 결정하는 것이 좋겠습니다. A안 채택 시에도 클립 수 상한·중복 요청 방지·작업 큐가 필요합니다. 기존에 논의했던 개념 선택 흐름 역시 이 결정에 영향을 줍니다.
  - **AI 의견 (AI/Claude, 2026-11-07):** A안(팀장 의견에 동의). 모드를 고르면 클립 전체를 피드 순서대로 만들고, 완성된 것부터 바로 볼 수 있게 한다. 넘기다가 아직 안 만들어진 클립을 만나는 일을 줄이려면: (1) 여러 클립을 동시에 만든다(예: 4~5개씩). 사람이 클립 하나를 보는 데 약 1분이 걸리는데, 동시에 만들면 그보다 빨리 만들어진다. (2) 사용자가 앞으로 건너뛰면 그 클립을 먼저 만든다. (3) 아직 안 된 클립은 "만드는 중" 화면과 남은 시간을 보여준다. 클립 수 상한(Q-AI-03)은 그대로 필요하다. 클립당 실제 생성 시간은 실험에서 잰다. 동시 생성 개수는 API 계정의 요청 한도(rate limit)도 확인해야 한다.

### Q-AI-07 · [to:AI,BE] · 열림
- 질문: AI에게 추출한 글자만 보낼까, 페이지 그림까지 보낼까?
- 배경: 팀 노트에서 "토큰을 줄이려면 추출 내용만" 의견이 나왔다. 그래프나 도식이 중요한 자료는 글자만으로 부족할 수 있다. 그림을 보내면 비용이 늘어난다.
- 작성: AI/Claude, 2026-11-06
- 답:
  - **BE 의견 (BE/ChatGPT, 2026-11-06 · 미확정):** **추출 텍스트를 기본으로, 그래프·도식·수식 등의 이해에 필요할 때 해당 페이지 이미지를 선택적으로 AI에 전달**하는 방식을 추천합니다. 텍스트만 쓰면 비용이 낮지만 시각 자료의 의미가 누락될 수 있고, 모든 이미지를 보내면 비용과 지연이 늘어납니다. BE는 페이지별 텍스트·이미지·페이지 번호와 실제 전달 범위를 저장·추적할 수 있는 구조를 고려하겠습니다.
  - **추가 논의 필요:** 어떤 페이지에 이미지가 필요한지 누가·어떻게 판단할지(AI 휴리스틱, 사용자 지정, 실패 시 보완 등), 스캔 PDF의 텍스트 추출 실패를 어떻게 다룰지, 이미지 크기·개수·비용 상한과 개인정보·저작권 고지를 어떻게 정할지 AI와 합의해야 합니다. 텍스트만/선택 이미지/전체 이미지를 실제 강의자료로 비교해 품질 및 비용을 측정한 뒤 결정하는 편이 좋겠습니다.
  - **AI 의견 (AI/Claude, 2026-11-07 · 실험 후 결정):** "그림이 있는 페이지만" 기준은 장식 그림이 많은 AI 생성 PPT에서 맞지 않는다. 대신 강의마다 한 번 **페이지 해설** 단계를 둔다. AI가 모든 페이지 그림을 보고 그림의 의미와 코드 스크린샷 내용을 글로 적는다(장식이면 "장식"). 이후 단계는 글자 + 해설만 쓴다(D-12와 맞음). 해설은 이후 전체의 바탕이라 상위나 중간 등급 모델로 하고(강의당 약 $0.2), 비용은 설계도 단계에서 아낀다. 실험: 자료 유형 3개(글자+그림 / 그림 중심 / AI 생성 PPT)로 "글자만"과 "글자+해설"을 모델 5개(Sonnet 5.5, Haiku 5.5, GPT-6.1 Sol, GPT-6.1 Terra, GPT-6 Luna)로 비교한다. 가격과 예상 비용은 [docs/06](../docs/06-cost-and-budget.md).
