## 회의 전에 각자 할 것

- 시작 루틴을 하고, 내 역할에게 온 질문과 제안서에 답한다. 답했으면 메신저로 알린다.

| 동시 생성 수 | 개발 중 1개, 시연은 3~4개 목표(요청 한도 보고) | P-BE-02 AI 7번 |

### 3. 남은 결정

- **모드 (Q-AI-03):** 처음 보기, 복습, 시험 대비 3개를 1단계에 모두 구현한다. API 값 이름을 정한다(후보: `intro`, `review`, `exam`). 클립 수는 상한만 두고 실험 후 정한다.
- **원본 페이지 표시:** 팀장 의견은 버튼을 누르면 옆 패널이 열리는 방식(유튜브 웹 쇼츠처럼). 패널은 지금 장면의 페이지를 따라 바뀐다. PDF 전체를 자유롭게 넘기는 기능은 1단계에서 뺀다(P-AI-02 AI 9번).
- **시연 기기 (Q-AI-12, Q-AI-14):** 팀장 의견은 노트북. 정해지면 FE는 PC 화면을 먼저 만든다.
- **협업 방식 (Q-FE-01):** 문서와 샘플은 main에 바로, 기능 코드는 브랜치에서 검토 후 합치기. PR 사용 여부와 합치는 담당을 정한다. 아래 FE 안건 참고.

### 4. 예산과 키

- 팀장 안: OpenAI, Anthropic에 각각 최소 금액 충전. 콘솔에서 월 지출 한도를 건다([docs/06](../../docs/06-cost-and-budget.md)).
- 키가 정해지면 AI가 실제 결과 샘플(설계도 + 음성 + 문장별 시간) 제공 날짜를 정한다.
- TTS 서비스(Q-AI-10)는 키가 생기면 같은 한국어 문장으로 들어 보고 고른다.

### 5. 11/11 피드백 준비

- 보여줄 것: 업로드부터 클립 목록까지 화면(FE), 샘플 설계도 재생(가능하면), 비용 추정.
- 물어볼 것: 학습 단계 모드가 와닿는지, 클립 길이와 개수, 근거 페이지 표시의 가치.
- NotebookLM 짧은 영상 기능을 사람이 직접 써 보고 비교 화면을 캡처한다(Q-AI-15). 담당을 정한다.
