# 11/11 목표: 실제 클립 1개를 플레이어로 재생

> 상태: 확정 (D-34) · 담당: AI (팀장) · 최종 수정: 2026-11-09 · AI/Claude

## 목표

**11/11(수) 현직자 피드백 전까지**, AI가 **알고리즘 분할정복 자료**로 만든 실제 클립 결과 1개(설계도 + 음성 + 문장별 시간 + 페이지 그림)를 FE 플레이어에서 재생한다. 샘플 클립은 분할정복 자료로 한정한다.

### 11/11 필수 범위 ([docs/04](../docs/04-video-blueprint.md) 기준)

| 구분 | 11/11 필수 | 11/11 이후 |
|---|---|---|
| 부품 | texts(수식 포함), grids, codes, slides, diagrams | |
| 다이어그램 배치 | tree, row | column, cycle, layers |
| 자리 | top, middle, bottom | full |
| 동작 | 12개 모두 | |

분할정복 자료는 배열, 재귀 트리, 의사코드, 점화식이 중심이라 위 범위로 모두 표현된다. AI는 검사기의 "지원 배치 목록"을 tree, row로 두고 그 안에서만 설계도를 만든다. **FE 작업이 너무 많으면 팀장이 범위를 다시 줄인다.**

### 끝났다는 기준

- [ ] 분할정복 실제 결과 1개가 처음부터 끝까지 음성, 자막, 동작이 맞춰 재생된다
- [ ] 일시정지, 뒤로·앞으로 탐색, 반복을 해도 화면이 같은 상태로 돌아온다
- [ ] AI의 "분할정복 부품 샘플"이 모두 그려진다 (위 11/11 필수 범위 전부)

### 이번 목표에서 하지 않는 것

PDF 업로드부터 자동 생성까지의 연결, 피드 넘기기, 상태 폴링, 모드별 분할, 분할정복 외 자료. 11/12(가능하면, Q-AI-17)와 11/13에 한다.

## 일정

| 언제 | AI | FE | BE |
|---|---|---|---|
| 11/9 밤 | API 키 결제, 검사기 시작 | 플레이어 골격과 상태 계산 (기존 샘플 3개로) | FastAPI 프로젝트 시작 |
| 11/10 오전 | 검사기, 분할정복 부품 샘플을 main에 올림 | 부품 구현 | 결과 제공 API |
| 11/10 저녁 | 분할정복 실제 결과 1~2개를 `samples/`에 올림 (D-32) | 부품 마무리, 음성 동기화 | FE와 연결 확인 |
| 11/11 피드백 전 | 결과 검사, FE 지원 | 실제 결과로 재생 확인 | 서버로 제공 (되면) |

FE는 실제 결과를 기다리지 않는다. 기존 샘플 1, 2(퀵 정렬, 분할정복 자료)와 분할정복 부품 샘플로 먼저 만들고, 저녁에 실제 결과로 바꾼다. 샘플 3(MVC)은 11/11 범위 밖이다.

## AI 필수

| 순서 | 할 일 | 기한 |
|---|---|---|
| 1 | API 키 결제와 설정 (팀장) | 11/9 |
| 2 | Python 검사기 `validate_blueprint` ([docs/04 검사기](../docs/04-video-blueprint.md#검사기) 규칙 전체) | 11/10 오전 |
| 3 | 샘플 정리: 샘플 3 좌표 수정, **분할정복 부품 샘플**(11/11 필수 범위의 부품, 배치, 자리, 동작을 모두 한 번 이상 쓰는 설계도. 예: 합병 정렬 재귀 트리 + 배열 + 의사코드 + 점화식). FE가 부품을 확인하는 기준 | 11/10 오전 |
| 4 | `extract_pdf`: 페이지 글자, 페이지 그림 PNG (PyMuPDF) | 11/10 |
| 5 | `make_blueprint`: 프롬프트, 구조화 출력, 검사, 1번 재생성. 분할정복 자료의 클립 계획은 손으로 써도 된다 | 11/10 |
| 6 | `make_audio`: 문장별 TTS, 길이 측정, 쉼 넣어 잇기, captions. TTS 서비스는 들어 보고 빠르게 고른다(Q-AI-10) | 11/10 |
| 7 | 결과 묶음 `samples/clip-01/`: `result.json`([ClipResult](../contracts/data-model.md#클립-결과-clipresult) 모양), 음성 파일, 근거 페이지 PNG | 11/10 저녁 |

11/11 이후: `describe_pages`, `plan_outline`, 샘플 모드, 모드별 분할.

## FE 필수

| 순서 | 할 일 |
|---|---|
| 1 | 플레이어 화면: 세로 화면, 다크 테마, 자리 3개 배치(top, middle, bottom), 자막 영역 |
| 2 | 상태 계산기: 설계도와 현재 문장으로 화면 상태를 만든다. 클립 시작부터 다시 계산한다([시간 규칙](../docs/04-video-blueprint.md#시간-규칙)). 동작 12개 모두 |
| 3 | texts: 스타일 4개, 수식은 KaTeX |
| 4 | grids: 한 줄, 2차원, 표, 칸 번호, 포인터, swap / setValue / move / 칸 강조 |
| 5 | codes: 줄 표시, markLine |
| 6 | slides: 페이지 그림에서 box만 보이기, focus 확대, mark 상자와 라벨 |
| 7 | diagrams: 배치 tree, row. 노드 box / circle, 선과 라벨, 노드·선 강조와 숨김 |
| 8 | 음성 동기화: 음성 현재 시간 → captions로 현재 문장 → 동작. 재생, 일시정지, 탐색, 반복 |
| 9 | 데이터 불러오기: `samples/clip-01/result.json`(또는 BE의 `GET /clips/{id}`)을 ClipResult 모양으로 읽기 |

- 선택: 원본 페이지 옆 패널(D-30). 단순 작업이라 다른 일이 끝나면 넣는다.
- 11/11 이후: 다이어그램 column, cycle, layers 배치, full 자리.
- 막히면 AI에게 지원을 요청한다(D-22).

## BE 필수

| 순서 | 할 일 |
|---|---|
| 1 | FastAPI 프로젝트 시작 (`backend/`) |
| 2 | 저장된 결과 제공: `GET /clips/{id}`, `GET /assets/{id}`. `samples/` 폴더에서 읽어 [api.md](../contracts/api.md) 모양으로 준다. DB는 아직 없어도 된다. CORS, 음성 탐색(Range) 확인 |
| 3 | 검사기 연결: `pipeline/`의 `validate_blueprint`로 결과를 내보내기 전에 검사 |

- FE는 BE 서버가 늦어도 파일로 직접 읽을 수 있다. BE 작업이 11/11 목표를 막지 않는다.
- 11/11 이후 본격: SQLite, 업로드, 작업 실행기, AI 함수 호출.

## 위험과 대응

- **FE 작업량이 가장 많다.** 그래서 11/11 범위를 분할정복용으로 줄였다. 11/10 저녁 점검에서도 밀리면 팀장이 범위를 더 줄이거나 AI 지원 범위를 정한다.
- **실제 결과 품질은 이번 목표가 아니다.** 형식이 맞고 재생되면 된다. 품질은 11/11 이후 올린다.
- **TTS 서비스 미정.** 11/10에 하나 골라 쓰고 나중에 바꿀 수 있다.
