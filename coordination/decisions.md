# 결정 기록

> 팀장(강현, AI 역할)만 작성한다. 새 결정은 맨 아래에 추가한다.
> 상태 뜻: **확정** = 그대로 따른다 / **방향 합의** = 방향만 정했고 세부는 미정이다
> 바꾸고 싶으면 `proposals/`에 제안서를 쓴다. 결정을 뒤집으면 새 항목으로 적고, 이전 항목에 "D-xx로 대체"라고 표시한다.

### D-01 · 확정 · 2026-11-06
**웹 서비스로 만든다.** 세로 숏폼을 웹에서 재생한다(유튜브 쇼츠를 웹에서 보는 형태). 옆에 공간이 있으면 참고한 자료를 함께 띄운다. 앱은 시간이 남으면 한다.
근거: 팀 회의 노트

### D-02 · 확정 · 2026-11-06
**영상 길이는 내용에 따라 달라진다.** 길이를 고정하지 않는다.
근거: 강현

### D-03 · 확정 · 2026-11-06
**수업 필기와 기출을 추가로 입력받는 기능은 이번 범위에서 뺀다.** 변수가 너무 많아진다.
근거: 강현

### D-04 · 확정 · 2026-11-06
**구현 범위를 1~3단계로 나누고, 목표는 2단계까지다.** 단계별 내용은 `docs/01-product.md`에 있다.
근거: 강현

### D-05 · 방향 합의 · 2026-11-06
**영상 생성 AI 대신 "영상 설계도 + 브라우저에서 그리기" 방식으로 간다.** 형식, 부품, 도구는 미정이다(Q-AI-09).
근거: 강현. 자세한 설명 요청 예정

### D-06 · 방향 합의 · 2026-11-06
**외부 AI API(Claude, OpenAI 등)를 쓰고, 자체 모델 학습이나 오픈소스 모델 운영은 하지 않는다.** 해커톤 규정상 외부 API 사용에 제한이 없다. 어떤 모델을 쓸지는 미정이다.
근거: 팀 회의 노트, 강현

### D-07 · 확정 · 2026-11-06
**역할: 강현 = 팀장이자 AI 담당, 프론트엔드 1명, 백엔드 1명.** FE와 BE 담당자 이름은 `roles/`에 적는다.
근거: 팀 회의 노트, 강현

### D-08 · 확정 · 2026-11-06
**일정: 11/10까지 사전 개발 초반부, 11/13 오프라인 14시간 개발.**
근거: 강현

### D-09 · 확정 · 2026-11-06
**`contracts/` 폴더를 파트 사이의 공용 기준으로 삼는다.** API 명세는 각자 에이전트와 논의해서 함께 만든다. 확정 이후 변경은 팀장 승인을 받는다.
근거: 강현

### D-10 · 확정 · 2026-11-06
**협업은 저장소를 통한 에이전트 간 소통 방식으로 한다** (`AGENTS.md`, `docs/08-collaboration.md`). 운영해 보며 고친다.
근거: 강현

### D-11 · 방향 합의 · 2026-11-06
**학습 단계 관점으로 클립을 나눈다.** 클립마다 중요도를 붙이는 방식이 아니라, 모드(처음 보기 / 복습 / 시험 대비 등)에 따라 나누는 방식과 클립 수가 달라진다. 모드 이름과 기준은 미정이다(Q-AI-03).
근거: 강현
