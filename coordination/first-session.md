# 첫 세션 안내 (에이전트용)

> 상태: 운영하면서 수정 · 담당: AI (팀장) · 최종 수정: 2026-11-06 · AI/Claude

`me.local.md`가 없는 사람이 `시작 루틴 해줘`라고 하면, AGENTS.md 4절의 1단계(`git pull`) 다음에 아래 순서를 따른다.
한 단계가 끝날 때마다 짧게 질문이 있는지 묻고, 사용자가 괜찮다고 하면 다음 단계로 넘어간다. 한 번에 길게 설명하지 않는다.

1. **나 소개 받기:** 이름, 역할(AI/FE/BE), 쓰는 도구를 묻고 `me.local.md`를 만든다(형식은 AGENTS.md 3절).
2. **프로젝트 소개:** `README.md`, `docs/01`~`docs/03`을 읽고 무엇을 왜 만드는지 쉽게 설명한다.
   `decisions.md`에서 `확정`인 것과 아직 논의중인 것을 나눠서 말한다.
3. **내 역할 소개:** `coordination/roles/내역할.md`를 읽고, 맡을 일과 다른 역할과 주고받는 것을 설명한다.
   역할별로 같이 볼 문서: FE는 `docs/04`, BE는 `contracts/`, AI는 `docs/05`
   역할 파일의 책임은 팀장이 쓴 초안이니, 다르게 생각하는 부분이 있으면 메모해 두자고 말한다.
4. **협업 방식 소개:** 다른 사람의 에이전트와는 저장소 파일로 소통한다는 것, 매일 쓰는 요청 문장(`docs/00-onboarding.md` 5절)을 짧게 알려준다.
5. **평소 루틴:** AGENTS.md 4절의 3~4단계를 한다. 나에게 온 질문, 요청, 의견이 필요한 제안서를 보고한다.
6. **제안서 의견:** 의견이 필요한 제안서가 있으면 같이 쓰자고 제안한다. 쓴 내용은 사용자에게 보여주고 확인을 받은 뒤, 내 역할 파일 현황과 함께 커밋하고 push한다.
