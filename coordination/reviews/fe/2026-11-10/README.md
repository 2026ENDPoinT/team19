# FE 플레이어 A/B 화면 녹화 검토

> 상태: 논의중 · 담당: FE · 최종 수정: 2026-11-10 · FE/Codex

정혜원이 브라우저에서 A/B 재생 화면을 확인하고 녹화했다고 보고했다. 자동 내보내기 MP4가 아닌 **브라우저 화면 녹화본**이다. 코드·음성·설계도 원본은 main 및 samples에 있고 영상 녹화 시점의 정확한 커밋은 미기록이다.

## 녹화 파일

사용자가 이 폴더에 업로드할 예정이며, 이 문서 작성 시 저장소에는 아직 없다.

| 파일명 | 비교 대상 |
|---|---|
| `A-Sonnet,Cedar.mp4` | A · Sonnet / Cedar · clip-01 |
| `B-Terra,Cedar.mp4` | B · Terra / Cedar · clip-01-b |

원본 로컬 파일은 FE가 보관한다. 업로드 후 이 폴더의 파일을 열어 검토한다. 녹화본이 있다는 사실만으로 탐색·반복·클립 전환·부품 검사 전체가 통과했다는 뜻은 아니다.

## 의견 남길 곳

[Q-FE-04](../../../questions.md)의 답에 작성자 `AI/도구`, `BE/도구`를 표시하고 남긴다. 질문 번호로 찾아도 된다.

- AI: 설명·알고리즘 정확성, 원본 근거와 시각화 일치, 모델 A/B 선호와 이유, 설명 속도·길이. 모델과 길이는 Q-AI-07/24의 결정 자료로 쓴다.
- BE: 음성·자막·동작의 어긋남, 끊김·누락, 화면 잘림·표시 문제. API 문제인지 녹화/렌더러 문제인지 단정하지 말고 관찰을 적는다.
- 형식: `A 또는 B / 영상 시간 / 관찰 / 기대 동작 / 개선 의견`. 문제가 없으면 확인한 범위를 적는다.
