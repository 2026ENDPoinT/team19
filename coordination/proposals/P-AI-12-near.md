# P-AI-12: 글을 다른 부품·노드·칸 옆에 붙이기 (`near`)

> 상태: 의견 수집중 · 제안: AI/Claude (팀원 합의) · 2026-11-14 · 방향 결정: D-60

[to:FE,BE]

## 무엇을 정하려는가

글(texts)을 자리(slot) 대신 **다른 부품·노드·격자 칸 옆에 붙이는** 방법. 좌표는 여전히 쓰지 않는다. AI는 "누구의 어느 쪽"만 쓰고 위치는 FE가 계산한다.

## 왜 필요한가

- 자리 3개(top/middle/bottom)에 "한 자리에 하나" 구조라, 배열 옆 이름표, 값을 주인 밑에 두기, 제목 밑 상태 줄 같은 표현을 못 했다. 그동안 격자 칸 우회, `place`의 위 자리 예외 같은 규칙을 덧댔다.
- 팀원 평가: "성공 1 밑에 P(X=1)", "배열 옆에 글자".

## 형식

```json
{ "id": "k1", "style": "keyword", "content": "피봇 8", "hidden": false,
  "near": { "target": "g1", "side": "below", "cell": "4" } }
```

| 칸 | 내용 |
|---|---|
| `near.target` | 붙을 주인 id: 부품(격자·다이어그램·코드·글) 또는 다이어그램 노드 |
| `near.side` | `above` / `below` / `left` / `right` |
| `near.cell` (생략 가능) | 주인이 격자일 때 칸 위치("4", "1,2"). 그 칸 바로 옆에 붙는다 |

- `near`가 있는 글은 `slot`을 쓰지 않고 자리도 차지하지 않는다(있어도 무시).
- 쓸 수 있는 글: body, keyword, formula. title·headline은 안 된다.
- 주인이 화면에 있는 동안만 보일 수 있다. 주인이 움직이면(`place`, 칸 swap 아님) 따라간다. 칸에 붙은 글은 칸 자리를 따라간다(값이 바뀌거나 swap돼도 칸 위치 기준).
- show/hide/highlight/setText/stamp/done 등 글에 되는 동작은 그대로 된다.
- 넘칠 때: 화면 밖으로 나가면 FE가 안쪽으로 밀어 넣는다(겹침 최소화는 FE 판단).

## AI가 지킬 것

- 주인 하나에 붙은 글 2개 이하, 15자 안팎.
- 주인을 hide하기 전에 붙은 글을 먼저 hide한다(검사기가 확인).

## 순서

AI는 검사기·프롬프트를 **미리 만들어 두고 꺼 두었다**(`pipeline/validate.py`의 `SUPPORTED_NEAR = False`). FE가 구현해 알리면 이 값을 True로 바꾸는 것만으로 켜진다.

## 영향받는 문서와 파트

- `docs/04-video-blueprint.md`: texts 칸(AI가 결정 뒤 고친다).
- FE: 붙은 글 위치 계산(부품·노드·칸의 화면 위치 기준), 주인 따라가기, 넘침 처리.
- BE: 설계도를 그대로 저장·전달하므로 영향 없을 것으로 본다.
