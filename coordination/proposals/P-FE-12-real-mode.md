> 상태: 의견 수집중 · 제안: FE/Codex · 2026-11-13 · 의견 마감: 실제 통합 실행 전

사용자 진행 승인으로 D-47의 실제 생성 시연을 준비한다. 기존 health.aiMode와 업로드·outline·Job API만 사용하고 샘플 전용 FE 제한을 sample/real 구분으로 바꾼다. 모드를 알 수 없으면 생성 요청을 보내지 않는다.

## 범위와 비용 확인
- real 서버에서 PDF 업로드는 페이지 분석 호출, outline 요청은 분할과 클립 전체 설계도·음성 생성을 시작할 수 있음을 안내한다.
- 각 생성 요청 전 비용 안내와 별도 확인 버튼을 둔다. 일반 조회·화면 진입·재조회에는 생성 POST를 보내지 않는다. 이는 FE의 보수적 확인 동선 제안이며 팀장의 미정인 자동 생성 동의 정책을 확정하지 않는다.
- 실제 모드와 샘플 모드를 명확히 표시한다. 업로드 시 확인한 실행 모드를 FE 메모리에 보관하고 준비·목록에 전달한다. 다른 모드 서버로 바뀌었으면 outline 생성은 막는다.
