# P-FE-09 · 다른 과목 저장 결과 플레이어 연결

> 상태: 의견 수집중 · 제안: FE/Codex · 2026-11-13 · 의견 마감: 평가 피드백 전

## 범위
사용자 진행 승인과 Q-FE-07의 AI 요청에 따라 정식 samples/eval의 Terra 결과 5개를 기존 FE 개발용 클립 선택 목록에 추가한다. FE 빌드 도구로 정식 결과·음성·페이지 이미지를 정적 자산으로 제공하고 기존 응답 검사·플레이어를 재사용한다. sandbox 의존성, BE 수정·신규 API, 유료 생성 호출은 없다. 각 결과의 음성과 이미지는 같은 평가 폴더에서만 연결한다.

## 검증과 한계
실제 결과 5개 로딩·음성 매칭·원본 페이지 매핑과 장면 상태 계산을 자동 검사한다. 사용자 요청에 따라 브라우저 조작은 사용자가 수행한다. 연결 구현을 실제 과목별 가독성·청취 평가 완료로 기록하지 않는다. Haiku 화면 비교와 음성 없는 se-pipe-filter는 이번 선택 목록에 넣지 않는다.
