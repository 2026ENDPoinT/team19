# P-AI-08: 테두리 없는 다이어그램 노드 (`shape: "text"`)

> 상태: 의견 수집중 · 제안: AI/Claude (팀장 요청) · 2026-11-14 · 방향 결정: D-54

[to:FE,BE]

## 무엇을 정하려는가

다이어그램 노드 모양에 `text`를 더한다. 네모·동그라미 없이 라벨 글자만 그린다.

## 왜 필요한가

- 낱말이나 개념을 나란히 비교·나열할 때(최대화 · 최소화, 국소 · 전역) 네모 칸에 넣으면 어색하다는 팀장 의견(11/14).
- 그동안 AI는 이런 비교를 격자(배열 칸)로 그려 더 어색했다. 이제 프롬프트에서 낱말 표를 격자로 만들지 않고 다이어그램(row 나란히, column 위아래)으로 그리게 바꿨다. 이때 네모가 없어도 되는 경우가 많다.

## 형식

```json
{ "id": "n1", "label": "최대화", "shape": "text" }
```

| 항목 | 내용 |
|---|---|
| 모양 | 테두리·배경 없이 라벨 글자만. 크기 계산과 선 끝점은 box와 같게 본다(글자 상자 기준) |
| 강조 | **FE가 정한다**(글자색 바꾸기, 밑줄 등). 다른 노드처럼 `highlight`/`unhighlight` 대상이다 |
| 섞어 쓰기 | 한 다이어그램 안에 box·circle·text를 섞을 수 있다 |
| 도장(P-AI-07) | text 노드에도 찍을 수 있다 |

## AI가 지킬 것 (프롬프트, FE 구현 뒤 켬)

- 비교·나열하는 낱말·개념은 `text`.
- 단계, 구성 요소처럼 "물건" 같은 것은 `box`. 순환 구조의 상태는 `circle`.

## 순서

D-46, P-AI-06, P-AI-07과 같다. FE가 구현해 알리면 AI가 검사기의 모양 목록에 `text`를 넣고 프롬프트에 규칙을 넣는다. 그 전에는 쓰지 않는다.
