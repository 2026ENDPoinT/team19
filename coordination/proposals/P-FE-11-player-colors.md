# P-FE-11 · 네온 팔레트와 설명 구간 수식 강조

> 상태: 결정됨 (D-46) · 제안: FE/Codex · 2026-11-13 · 최종 수정: 2026-11-13 · AI/Claude

사용자 요청으로 FE 플레이어가 그리는 선·도형 테두리·강조선은 파랑 #15F4EE, 노랑 #d0ee17, 초록 #6cfd33, 분홍 #f52e7f만 사용한다. 같은 구조는 같은 색을 유지하고 강조는 선 두께·밝기로도 구분한다. 원본 이미지 내부 선은 재색칠하지 않는다. 사용자 후속 요청으로 상단 재생·소리·더보기·전체화면 아이콘은 흰색을 유지한다.

FE 내부 표시 개선으로 적용한다. 기본 도형·연결선은 파랑, 격자 테두리는 초록, 설명 영역·코드 강조는 노랑, 수식 설명 강조는 분홍을 사용한다. 트리 노드는 강조 여부와 무관하게 같은 테두리 색을 유지한다.

기존 highlight/unhighlight 논리 상태와 계약은 유지한다. FE 수식 표시는 해당 수식이 highlight되는 자막 구간에만 색을 바꾸고, 끝나면 기본 글자색으로 복원한다(탐색·정지·반복도 음성 시간 기준). 자막에 정확한 $수식 항$ 표기가 있으면 그 항만, 없으면 수식 전체를 강조한다. 임의 의미 추측으로 특정 숫자·기호를 선택하지 않는다.

[to:AI] 수식 설명 시 기존 자막 lines에서 설명 대상 항을 $...$로 명시할 수 있는지 검토해 주세요. 현 captions가 대상 항을 명시하지 않으면 FE는 세부 항별 설명을 확정할 수 없습니다. 새로운 API 필드는 추가하지 않습니다. 이후 항별 정식 타이밍 계약이 필요하면 별도로 협의합니다.

## 추가 제안 · 수식 항·숫자별 강조 (2026-11-13 사용자 요청)
[to:AI] 수식 하나를 통째로 강조하는 것에 더해, **설명하는 항·숫자·기호를 개별 지정**할 수 있는 생성 방식과 데이터 표현을 제안해 주세요.

예: `z = α₁v₁ + α₂v₂`에서 첫 항을 설명할 때 `α₁v₁`만 분홍색으로 표시하고, 설명이 끝나면 흰색으로 복원합니다. 두 번째 항 설명에서는 `α₂v₂`만 강조합니다. 여러 항을 비교할 때는 네온 파랑·노랑·초록·분홍 중 서로 구별되는 색을 사용하되, 같은 의미의 항은 비교 구간 안에서 같은 색을 유지합니다. 기본 글자는 흰색이며 설명 종료 후 원복합니다.

### AI에게 필요한 정보
- 대상 수식(기존 text id), 강조할 부분, 색, 시작·끝 자막 lineIndex를 구분해야 합니다. 타이밍은 현재 문장별 captions에 연결하는 방향을 우선 검토하며, 문장 내부 초 단위 타이밍이 필요하면 별도로 협의합니다.
- 같은 기호가 수식에 여러 번 등장하면 ‘전부’인지 ‘몇 번째 항’인지 명확해야 합니다. 단순 문자열 치환으로 다른 변수·숫자·LaTeX 명령까지 색칠하지 않아야 합니다.
- 분수·첨자·지수·괄호 안의 항도 KaTeX 문법을 깨뜨리지 않고 지정할 수 있어야 합니다. 수식의 값·연산 의미는 변경하지 않습니다.
- 강조 지시를 TTS가 읽지 않도록 자막/수식 표시 정보와 speech를 구분합니다.

### 선택지와 추천
- **A. 기존 표현으로 시험:** 자막의 `$항$`과 기존 highlight를 사용합니다. 현 FE는 이 범위만 지원합니다. 색은 분홍 고정이고 동일 부분문자열의 반복 위치·복잡한 괄호 항·문장 여러 개에 걸친 유지에는 한계가 있습니다.
- **B. 항을 식별하는 정식 표현 협의(추천):** 항별 식별자/범위와 색·설명 구간을 별도로 표현해 반복 기호도 정확히 지정합니다. 구체적인 필드와 동작은 AI·FE가 검토하고 팀장이 결정한 뒤 구현합니다. 기존 args나 동작의 의미를 FE가 임의로 확장하지 않습니다.
- [to:AI] 실제 수식 1개로 강조 대상을 지정한 예시와 권장 표현을 알려 주세요. 프롬프트·검사기에서도 대상·색·구간의 유효성을 확인할 수 있는지 검토해 주세요. 유료 재생성 실행 요청은 아닙니다.
- [to:BE] B안으로 결과 형식이 확장되는 경우에만 새 정보의 저장·제공 보존 여부를 확인해 주세요. 지금 신규 API를 요구하지 않습니다.

### 완료 기준
같은 기호가 반복되는 수식, 분수·첨자·지수 수식에서 의도한 항만 색이 바뀌고, 설명 종료·장면 전환 시 원복해야 합니다. 정지·앞뒤 탐색·반복 재생에도 같은 시간은 같은 색을 보여야 합니다. 현재 항별 다색·정식 타이밍 지원은 미구현입니다.

## 의견
### AI
**AI/Claude (2026-11-13):** B안에 동의한다. 아래 표현을 추천한다. 기존 highlight 동작을 그대로 쓰고 args만 늘리며, 새 필드는 없다.

1. **항 표시:** AI가 수식 `content` 안에서 강조할 부분을 `\term{항id}{LaTeX}`로 감싼다. 항 id는 그 수식 안에서 겹치지 않는 영문 소문자·숫자·`_`다. 감싼 자리 하나만 가리키므로 같은 기호가 여러 번 나와도 헷갈리지 않는다. 분수·첨자 안도 감쌀 수 있다(`\frac{\term{n}{a+b}}{c}`).
2. **강조:** `{"line": 2, "do": "highlight", "target": "수식id", "args": ["r"]}`. args가 없으면 지금처럼 수식 전체, 있으면 그 항만 강조한다. `unhighlight`도 같다(args 없으면 모두 끔). 문장 단위라 기존 captions 시간에 그대로 맞는다. 여러 문장에 걸치면 unhighlight할 때까지 유지된다.
3. **색:** AI는 색을 정하지 않는다(docs/04 원칙 1). FE가 한 highlight의 args 순서대로 분홍 → 파랑 → 노랑 → 초록을 주고, 그 항은 끌 때까지 같은 색을 유지한다. 비교할 항은 한 highlight에 같이 넣는다.
4. **그리기:** FE가 KaTeX에 넘기기 전에 `\term{id}{X}`를 강조 중이면 `\textcolor{색}{X}`, 아니면 `{X}`로 바꾼다. 괄호 짝을 세는 짧은 함수면 된다. KaTeX 0.19.1로 시험했다: 실제 벨만 식에서 항 1개·2개 강조, 같은 `x`가 세 번 나오는 식에서 두 번째만 강조, 분수 분모 강조 모두 정상이었다.
5. **음성:** `\term`은 수식 `content`에만 쓴다. `lines`와 `speech`에는 들어가지 않으므로 TTS가 읽지 않는다.
6. **검사기(AI 몫):** `\term` 괄호 짝, 수식 안 항 id 중복, formula 외 사용, highlight args가 그 문장 시점의 수식(setText 반영)에 있는 항 id인지 확인한다.

**예시(강화학습 s4의 실제 식):**
```json
{"id": "t4_formula", "style": "formula", "content": "$Q^\pi(s,a)=\term{p}{\sum_{s'}P^a_{ss'}}\big[\term{r}{R^a_{ss'}}+\term{g}{\gamma\sum_{a'}\pi(s',a')Q^\pi(s',a')}\big]$"}
```
| 문장 | 동작 | 화면 |
|---|---|---|
| "다음 상태는 전이확률로 평균해요." | highlight t4_formula ["p"] | ∑P 부분만 분홍 |
| "그 안에서 먼저 즉시 보상을 받아요." | unhighlight ["p"], highlight ["r"] | R만 분홍 |
| "보상과 할인된 다음 가치를 비교해 볼게요." | highlight ["r","g"] | R 분홍, γ∑… 파랑 |
| "이렇게 둘을 더한 게 행동가치예요." | unhighlight (args 없음) | 모두 흰색 |

**순서:** FE가 `\term` 변환을 먼저 넣어야 한다. 넣기 전에 AI가 `\term`을 쓰면 KaTeX가 모르는 명령으로 오류를 낸다. 팀장이 승인하면 FE 구현 → AI 프롬프트·검사기 반영 → 강화학습 클립 재생성 순서로 간다. 지금 바로 되는 것으로 **수식을 setText로 한 부분씩 쌓아 가는 규칙**은 프롬프트에 넣었다(형식 변경 없음, Q-FE-09 답 참고).
