# P-FE-11 · 네온 팔레트와 설명 구간 수식 강조

> 상태: 의견 수집중 · 제안: FE/Codex · 2026-11-13 · 의견 마감: 다음 실제 결과 검토

사용자 요청으로 FE 플레이어가 그리는 선·도형 테두리·강조선은 민트 #4fe3c1, 노랑 #ffdf00, 코럴 #fb6b6e만 사용한다(11/13 사용자 후속 요청으로 이전 네 색 팔레트 폐기). 같은 구조는 같은 색을 유지하고 강조는 선 두께·밝기로도 구분한다. 원본 이미지 내부 선은 재색칠하지 않는다. 사용자 후속 요청으로 상단 재생·소리·더보기·전체화면 아이콘은 흰색을 유지한다.

FE 내부 표시 개선으로 적용한다. 도형·격자 테두리는 민트, 연결 화살표와 설명 영역·코드 강조선은 노랑, 수식 설명 강조는 코럴을 사용한다. 트리 노드는 강조 여부와 무관하게 같은 테두리 색을 유지한다.

기존 highlight/unhighlight 논리 상태와 계약은 유지한다. FE 수식 표시는 해당 수식이 highlight되는 자막 구간에만 색을 바꾸고, 끝나면 기본 글자색으로 복원한다(탐색·정지·반복도 음성 시간 기준). 자막에 정확한 $수식 항$ 표기가 있으면 그 항만, 없으면 수식 전체를 강조한다. 임의 의미 추측으로 특정 숫자·기호를 선택하지 않는다.

[to:AI] 수식 설명 시 기존 자막 lines에서 설명 대상 항을 $...$로 명시할 수 있는지 검토해 주세요. 현 captions가 대상 항을 명시하지 않으면 FE는 세부 항별 설명을 확정할 수 없습니다. 새로운 API 필드는 추가하지 않습니다. 이후 항별 정식 타이밍 계약이 필요하면 별도로 협의합니다.

## 추가 제안 · 수식 항·숫자별 강조 (2026-11-13 사용자 요청)
[to:AI] 수식 하나를 통째로 강조하는 것에 더해, **설명하는 항·숫자·기호를 개별 지정**할 수 있는 생성 방식과 데이터 표현을 제안해 주세요.

예: `z = α₁v₁ + α₂v₂`에서 첫 항을 설명할 때 `α₁v₁`만 코럴색으로 표시하고, 설명이 끝나면 흰색으로 복원합니다. 두 번째 항 설명에서는 `α₂v₂`만 강조합니다. 여러 항을 비교할 때는 민트·노랑·코럴 중 서로 구별되는 색을 사용하되, 같은 의미의 항은 비교 구간 안에서 같은 색을 유지합니다. 기본 글자는 흰색이며 설명 종료 후 원복합니다.

### AI에게 필요한 정보
- 대상 수식(기존 text id), 강조할 부분, 색, 시작·끝 자막 lineIndex를 구분해야 합니다. 타이밍은 현재 문장별 captions에 연결하는 방향을 우선 검토하며, 문장 내부 초 단위 타이밍이 필요하면 별도로 협의합니다.
- 같은 기호가 수식에 여러 번 등장하면 ‘전부’인지 ‘몇 번째 항’인지 명확해야 합니다. 단순 문자열 치환으로 다른 변수·숫자·LaTeX 명령까지 색칠하지 않아야 합니다.
- 분수·첨자·지수·괄호 안의 항도 KaTeX 문법을 깨뜨리지 않고 지정할 수 있어야 합니다. 수식의 값·연산 의미는 변경하지 않습니다.
- 강조 지시를 TTS가 읽지 않도록 자막/수식 표시 정보와 speech를 구분합니다.

### 선택지와 추천
- **A. 기존 표현으로 시험:** 자막의 `$항$`과 기존 highlight를 사용합니다. 현 FE는 이 범위만 지원합니다. 색은 코럴 고정이고 동일 부분문자열의 반복 위치·복잡한 괄호 항·문장 여러 개에 걸친 유지에는 한계가 있습니다.
- **B. 항을 식별하는 정식 표현 협의(추천):** 항별 식별자/범위와 색·설명 구간을 별도로 표현해 반복 기호도 정확히 지정합니다. 구체적인 필드와 동작은 AI·FE가 검토하고 팀장이 결정한 뒤 구현합니다. 기존 args나 동작의 의미를 FE가 임의로 확장하지 않습니다.
- [to:AI] 실제 수식 1개로 강조 대상을 지정한 예시와 권장 표현을 알려 주세요. 프롬프트·검사기에서도 대상·색·구간의 유효성을 확인할 수 있는지 검토해 주세요. 유료 재생성 실행 요청은 아닙니다.
- [to:BE] B안으로 결과 형식이 확장되는 경우에만 새 정보의 저장·제공 보존 여부를 확인해 주세요. 지금 신규 API를 요구하지 않습니다.

### 완료 기준
같은 기호가 반복되는 수식, 분수·첨자·지수 수식에서 의도한 항만 색이 바뀌고, 설명 종료·장면 전환 시 원복해야 합니다. 정지·앞뒤 탐색·반복 재생에도 같은 시간은 같은 색을 보여야 합니다. 현재 항별 다색·정식 타이밍 지원은 미구현입니다.
