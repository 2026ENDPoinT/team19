# P-FE-05: 플레이어 MP4 내보내기

> 상태: 의견 수집중 · 제안: FE/Codex · 2026-11-10 · 의견 마감: D-34 재생 점검 후 협의

## 무엇을 정하려는가
브라우저에서 설계도·자막·음성을 재생하는 결과를 MP4로 내려받는 기능의 범위와 담당을 정한다. 사용자는 MP4 내보내기를 AI·BE에 제안하고, 구현 전 FE 다운로드 메뉴는 준비 중으로 표시하는 데 동의했다.

## 왜 지금 필요한가
팀 피드백 공유를 위해 사용자가 현재는 직접 화면을 녹화한다. 저장된 TTS만 내려받는 것을 영상 다운로드로 표시하면 안 된다. 기존 BE 샘플 MP4는 현재 설계도 플레이어를 내보낸 결과가 아니므로 재사용하지 않는다. D-34의 필수 범위는 실제 재생이며 MP4 내보내기는 추가 기능 제안이다.

## 선택지
### A. BE 작업으로 MP4 생성
FE 렌더러와 동일한 장면·시간 규칙을 활용해 화면·자막·음성을 녹화/인코딩하고 파일을 제공한다. 서버 실행 환경, 추가 의존성, 처리 시간과 저장·실패 처리, API/Job 계약 확장 여부를 협의한다.
### B. 현재처럼 수동 화면 녹화를 유지
추가 서버 작업 없이 피드백에 사용할 수 있다. 자동 MP4 다운로드 기능은 이후에 구현한다.

## 제안자의 추천과 이유
D-34 재생 확인을 우선하고 A의 실현 방식·담당·비용을 AI·BE와 합의한다. 현재 FE에는 상단 조작 UI와 속도 선택을 구현하되, 영상 다운로드는 비활성화된 준비 중 항목으로 표시한다. 유료 호출·새 API·원본 samples 변경을 임의로 추가하지 않는다.

## 영향받는 문서와 파트
- [to:AI] 내보내기에 사용할 결과 버전과 음성·자막·동작 기준, 허용할 품질을 검토해 주세요. 학습 자료 비공개 원칙(D-23)을 유지하며 공개 공유 기능은 제안하지 않습니다.
- [to:BE] 기존 샘플 MP4와 구분되는 실제 플레이어 MP4 작업의 실행 환경·저장/제공·오류·API 영향과 담당 방식을 검토해 주세요.
- FE: 동일 렌더러/시간 규칙 제공과 진행·완료·다운로드 UI. 지금은 API 계약을 변경하지 않는다.

## 확인 기준
선택한 resultId의 그림·자막·음성이 동일 버전으로 포함되고, 처음부터 끝까지 길이·싱크·9:16이 보존돼야 한다. 현재 재생 속도를 반영할지 원속도 MP4만 만들지, 생성 중 실패/취소와 저장 정책은 팀장이 결정한다.
