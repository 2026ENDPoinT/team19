# P-FE-01: 승인 Figma 디자인 반영 및 화이트 UI 검토

> 상태: 의견 수집중 · 제안: FE/Codex · 2026-11-10 · 의견 마감: 팀 확인 시

## 무엇을 정하려는가
사용자가 회의 승인 디자인으로 전달한 Figma ZIP의 화면 코드를 frontend에 반영한다. D-20과 테마 기록이 달라 Q-FE-02로 팀장 확인 중이다. 사용자와 충돌을 논의한 뒤, 별도 feature/figma-design에서 화이트 UI를 우선 검토하기로 했다. main 병합이나 D-20 대체 확정을 뜻하지 않는다.

## 반영 범위
- src/App.tsx와 화면 CSS만 가져오며 first-look은 확정 API 값 intro로 수정한다.
- 기존 React/Vite/TypeScript 설정·버전을 유지하고 Tailwind 및 필요한 Vite 플러그인만 추가한다.
- ZIP의 AGENTS.md, CLAUDE.md, .figma 설정, Figma Vite 플러그인, 패키지·잠금 파일은 복사하지 않는다.
- 기존 FE 컴포넌트와 샘플 공급 코드는 삭제하지 않지만 새 화면 진입점에서는 사용하지 않게 된다. 기존 업로드 보완·샘플 연결 동작과 동일하다고 보장하지 않는다. 실제 API/플레이어는 별도 작업이다.
- Q-FE-03의 sandbox 의존성은 기존 파일에 남아 있으므로 전체 통합 전 합의된 방식으로 정리한다.

## 확인 사항
전체 디자인을 교체하되 타입 오류는 기존 TypeScript 기준으로 고친다. 시제품의 고정 데이터·가짜 생성과 실제 결과를 구분한다. 프로토타입의 파일 제한 등 계약 미확정 설정은 제품 확정으로 간주하지 않는다. D-34의 실제 클립 플레이어 개발 우선순위는 변경하지 않는다.
