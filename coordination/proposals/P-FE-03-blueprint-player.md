# P-FE-03: 실제 클립 A/B 설계도 플레이어 구현

> 상태: 의견 수집중 · 제안: FE/Codex · 2026-11-10 · 의견 마감: 11/11 연결 확인 전

## 무엇을 정하려는가
D-34와 확정 계약 v0 범위에서 실제 분할정복 클립 A/B를 같은 FE 플레이어로 재생하는 구현 순서와 파트 간 연결을 제안한다. 계약 변경이나 범위 확대를 확정하는 문서가 아니다.

## 기준과 제외 범위
- 기준: docs/04, contracts/api.md·data-model.md, coordination/plan-first-clip.md, backend/INTEGRATION-NOTES.md.
- 필수: texts(KaTeX 수식), grids, codes, slides(focus/mark), diagrams(row/tree), top/middle/bottom, 동작 12개. parts-test로 필수 부품 전체 확인.
- 제외: full·column/cycle/layers, 업로드부터 자동 생성 연결, 모드 분할, 피드 넘기기, 강의함·저장·재생성. 원본 옆 패널은 필수 완료 후 선택 작업.
- 플레이어 영역과 blueprint.theme은 dark 유지. 웹 UI 테마는 Q-FE-02/P-FE-01 결정 기록을 따르며 본 제안으로 바꾸지 않는다.

## 선택지
- A. 기존 시제품 전체 흐름을 먼저 실제 API와 연결: D-34 필수 재생 개발이 늦어질 수 있다.
- B. 저장된 실제 클립과 부품 샘플을 바로 읽는 독립 플레이어부터 구현: D-34에 맞고 각 파트를 분리 검증할 수 있다. B안을 추천한다.

## 구현 블록과 완료 기준

| 순서 | FE 작업 | 확인 |
|---|---|---|
| 1 | ClipResult 타입과 공급 함수, A/B 선택, 로딩·오류 | GET /clips/clip-01 및 clip-01-b 응답의 result를 읽고 audioUrl은 BE 기준으로 해석 |
| 2 | 원본을 변경하지 않는 순수 상태 계산기 | 시간에서 현재 문장·장면·12개 동작을 계산. 뒤로 탐색·clear:false·반복 결과 동일 |
| 3 | 자리 3개와 부품 렌더러 | texts·grids·codes·slides·row/tree를 parts-test로 확인. 미지원 부품은 명시 오류 |
| 4 | 음성·자막·동작 동기화 | audio.currentTime 단일 기준. 재생/정지/탐색/반복, 다음 문장 시작 시 이전 동작 최종화 |
| 5 | A/B 전환과 실제 연동 점검 | 이전 음성 정지, 같은 결과의 설계도·자막·음성 함께 교체. Q-BE-02/03에 검증 결과 기록 |

컴포넌트/함수 단위로 코드를 보여주고 설명한다. 지원 목록을 임의 확대하거나 다른 역할 폴더를 수정하지 않는다. 구현 브랜치는 P-FE-02가 확정되기 전까지 현행 feature 규칙을 따른다.

## 세부 재생 기준
- 음성 currentTime → captions의 sceneId/lineIndex → 장면 상태. 문장/장면 쉼과 전환은 docs/04 시간 규칙 그대로 따른다.
- 기준 상태를 복사하고 클립 시작부터 현재 시점까지 적용해 원본 불변성과 반복 재현성을 확보한다. 같은 swap 중복 적용을 막는다.
- 한 자리에 보이는 부품 1개. 강조는 값이 아니라 칸에 붙인다. 슬라이드 좌표는 원본 페이지 기준이며 box 범위 안에서 focus/mark한다.
- 재생은 사용자 동작에서 시작하고 재생 거절/미디어 오류를 안내한다. 프레임 갱신과 이벤트 구독은 클립 전환·언마운트 시 해제한다.
- 전체 길이·resultId를 하드코딩하지 않는다. 같은 결과 버전의 데이터와 음성을 사용한다. Figma 시제품 가짜 결과와 실제 재생을 구분한다.
