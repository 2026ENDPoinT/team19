## 현황 (세션마다 갱신)

> 최종 갱신: 2026-11-10 · BE/Codex

### 최근 한 일

- 실제 A/B 결과·MP3 제공 커밋 `689553d`는 main에 병합·Push 완료됐다. 시작 시 미커밋 변경은 없었고 최신 `origin/main`(`15f0067`)을 충돌 없이 반영했다. 과거 Push 승인 대기·main 병합 전 상태는 해소됐다.
- A=`/clips/clip-01`, B=`/clips/clip-01-b`, 음성은 각각 `/assets/clip-01-audio`, `/assets/clip-01-b-audio`다. 현재 A 138.8초/25문장, B 114.25초/23문장이며 resultId·길이는 파일에서 읽는다. [FE 연동 안내](../../backend/INTEGRATION-NOTES.md)를 공유했고 FE가 Q-BE-02/03에서 확인했다.
- 각 고정 ID는 자기 폴더의 JSON·MP3만 사용한다. 공식 검사기·자막 대응/순서/시간·실제 음성 길이를 검사하며 직접 음성 요청도 검증한다. PDF/pypdf·SQLite·Job·샘플 MP4·parts-test는 유지했고 AI/FE 코드는 수정하지 않았다.
- 이전 구현 검증에서 노트북 117개 통과(BE 93 + 검사기 22 + PyMuPDF 추출 2). 실제 Uvicorn 8000 포트에서도 A/B/parts-test의 원본 JSON·음성 일치, 200·206·416·HEAD·If-Range·CORS를 확인했다. 이번 세션은 문서 검토만 하며 테스트 재실행·유료 AI 호출은 하지 않았다.
- P-FE-01/02/03에 BE 의견, Q-FE-03에 공식 fixtures 위치·소유권 의견을 기록했다. main과 원격 frontend(`115f6c3`) 모두 sandbox 직접 의존성이 없고 `backend/fixtures/`는 아직 없다. Q-BE-01의 실제 PNG 제공은 완료됐으며 저장된 샘플 이미지 API 제공과 구분했다.
