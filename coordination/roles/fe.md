# 역할: 프론트엔드 (FE)

> 이 파일은 FE 역할만 고친다. 다른 역할은 읽기만 하고, 요청은 `questions.md`에 남긴다.
> 아래 "책임"은 팀장이 쓴 초안이다. FE 담당자가 자기 에이전트와 검토하고 고쳐서 확정한다.

- 담당: 정혜원
- 도구: Codex

## 책임 (초안)

- 업로드 화면, 모드 선택, 진행 상태 화면
- 세로 피드: 위아래로 넘기기, 반복 재생
- 원본 페이지 옆 패널
- **영상 설계도 플레이어**: 설계도를 읽고 부품을 그리고 움직이며, 음성과 자막을 맞춘다
- (2단계) 내 강의함, 클립 저장, 다시 만들기 요청 화면

## 다른 역할에게 주는 것

- AI에게: 설계도 중 그리기 어렵거나 애매한 부분에 대한 피드백
- BE에게: 화면에 필요한 데이터 목록 (API 요구사항)

## 다른 역할에게서 받는 것

- AI에게서: 설계도 형식, 샘플 설계도
- BE에게서: API, 샘플 응답

## 1단계 완료 기준 (초안)

샘플 데이터로 피드에서 클립이 재생되고, 옆에 원본 페이지가 보인다. 이후 실제 API로 바꿔도 똑같이 동작한다.

## 알아둘 위험

- FE 담당자 의견: 작업량이 많아도 우선 현재 책임 범위를 직접 구현해 본다. 실제로 진행하면서 일정이나 작업량이 감당하기 어렵다고 판단되면 AI 담당자에게 일부 구현 지원을 요청한다(Q-AI-22). 현재는 작업 분담을 요청하지 않는다.
