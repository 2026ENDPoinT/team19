# FE 실제 클립 시연 점검

> 상태: 초안 · 담당: FE · 최종 수정: 2026-11-10 · FE/Codex

[D-34 목표](plan-first-clip.md)는 11/11 피드백 전 실제 분할정복 클립 재생이다. 오늘(11/10)은 부품 마무리·음성 동기화와 진행 보고를 준비한다. 이 문서는 점검 절차이며 **아래 브라우저 검사는 모두 미실시**다.

## 확인할 코드와 실행

- 최신 이동 효과는 `frontend`의 `e3cf124`(교환 `d4a0932` 포함)에 있다. 작성 시점 main에는 이 두 기능이 아직 병합되지 않았다. 브라우저 점검 기록에는 실제 확인한 브랜치와 커밋을 적는다.
- main의 기존 플레이어도 재생 점검 가능하다. 최신 교환·포인터 이동 검사는 frontend에서 한다. 미커밋 작업이 있으면 먼저 정리하고 브랜치를 전환한다.
- 서버는 PC를 재시작하거나 실행을 종료하면 다시 켜야 한다. localhost는 서버를 켠 PC의 브라우저에서 연다.

PowerShell 터미널 1 — 저장소 루트에서 [BE 실행 안내](../backend/README.md#실행-windows-powershell-저장소-루트)의 Python 환경을 준비하고 다음을 실행한다. 아래 `python`은 해당 BE 환경의 실행 파일을 뜻한다. 필요하면 안내의 `$team19Python` 경로와 `&` 호출로 바꾼다.

```powershell
cd C:\GitHub\team19
$env:AI_MODE = 'sample'
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

PowerShell 터미널 2 — 최신 이동 효과를 확인할 때:

```powershell
cd C:\GitHub\team19
git switch frontend
git pull --ff-only
cd frontend
npm ci
npm test
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

`npm ci`는 의존성 설치가 필요할 때 실행한다. 자동 검사에 사용한 Node는 22.14.0이며 `--experimental-strip-types`를 지원해야 한다. 서버 터미널에 입력 대기줄이 돌아오지 않는 것은 실행 중인 정상 상태다. 다른 명령은 새 터미널에서 실행하고 종료는 Ctrl+C로 한다.

PC 브라우저에서 http://127.0.0.1:5173/ → **실제 클립 A/B 연결 확인**을 누른다. PDF 업로드나 생성 버튼을 누를 필요 없다. A/B는 실제 저장된 TTS, 부품 검사는 문장 시작 신호음이다. 새 생성·유료 API 호출은 하지 않는다.

## 점검 순서

| 순서 | 조작 | 통과 기준 | 결과 |
|---|---|---|---|
| 1 | A 선택 후 재생 | 설명 음성·자막·시각화가 처음부터 끝까지 진행. 오류·빈 화면 없음 | 미실시 |
| 2 | A 중간에 일시정지 후 재개 | 음성·배열·포인터가 함께 멈추고 해당 시점에서 이어짐 | 미실시 |
| 3 | A의 약 42~115초를 앞뒤로 탐색 | s4~s6에서 이전 장면의 배열·코드가 유지되고 값·강조·포인터가 중복 적용되지 않음 | 미실시 |
| 4 | 처음부터 버튼, 끝까지 재생해 반복 | 시작 화면으로 복원. 직전 반복의 강조·값·확대가 남지 않음 | 미실시 |
| 5 | A 재생 중 B 선택, 다시 A 선택 | 이전 음성이 멈추고 새 결과의 제목·길이·음성·화면이 함께 교체됨 | 미실시 |
| 6 | B 전체 재생 및 약 33~80초 앞뒤 탐색 | s3~s4의 이어 쓰기와 복원이 정상. A의 화면·음성이 섞이지 않음 | 미실시 |
| 7 | 부품 검사 전체 재생 | 아래 모든 부품과 동작을 확인. 신호음을 TTS 실패로 오해하지 않음 | 미실시 |
| 8 | PC 창 너비 1024px 이상에서 원본 페이지 보기 | 현재 장면의 전체 근거 페이지가 옆에 표시되고 장면 전환·탐색을 따름. 열고 닫아도 재생 시간이 초기화되지 않음 | 미실시 |
| 9 | 재생 중 업로드 화면으로 돌아가기 | 이전 음성이 멈춤. 다시 들어갔을 때 겹쳐 재생되지 않음 | 미실시 |
| 10 | 서버 종료 후 화면 재진입, 서버 재실행 후 다시 불러오기 | 조회 실패 안내 후 정상 회복. 다시 불러오기는 GET 조회이며 생성 재시도가 아님 | 미실시 |

탐색 범위는 현재 samples의 captions 기준이며 샘플 교체 시 다시 계산한다. 장면은 앞 장면 마지막 문장 endSec에 바뀌므로 다음 설명 시작까지 짧은 쉼이 있다. 자막 사이 빈 구간도 정상이다.

## 부품 검사에서 볼 구간

| 현재 샘플 구간 | 확인할 것 |
|---|---|
| 0~8.55초 | 텍스트·수식·강조 |
| 8.55~25.8초 | row·tree 노드/선과 강조, 라벨 가독성 |
| 25.8~33.75초 | 배열 교환. 숫자만 이동하고 강조는 칸에 남는지 |
| 33.75~48.75초 | 격자·코드 줄 강조·값 변경·포인터 이동 |
| 48.75~57.3초 | clear:false 이어 쓰기, 숨기기·보이기·텍스트 변경 |
| 57.3~70.95초 | 원본 그림, 확대·영역 강조·해제. 확대 중 정지/탐색 복원 |

모든 부품에서 글자·수식 잘림, 가로/세로 스크롤 접근성, 포인터 겹침, 트리 선·라벨, 긴 자막 가독성도 확인한다. 자동 계산 검사만으로 화면 가독성을 통과 처리하지 않는다.
