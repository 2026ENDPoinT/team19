# 팀원 강의자료·시각화 부품 관찰 노트

> **2026-11-14 저장소 공개(D-69)에 따라 강의 원본(PDF, PPT) 40개를 main에서 뺐다.** 각자 컴퓨터의 파일은 그대로이고 `.gitignore`로 다시 올라가지 않는다. 메모(`manifest.csv`, `note.md`)만 남긴다. 예전 커밋 기록에는 남아 있다.

> 상태: 제출 양식 초안 · 관리: 각 과목 제출자 · 작성: BE/ChatGPT, 2026-11-13

## 목적

각 팀원이 담당 과목의 **강의 PDF에서 어떤 내용이 중요한지**, **어느 페이지를 근거로 삼는지**, **어떤 영상 부품으로 보여 주면 좋을지** 짧게 기록합니다. 사람이 적은 메모를 AI의 분할·시각화 결과와 비교하기 위한 참고자료입니다. **실제 모델을 새로 학습하거나 레이블이 자동으로 정답으로 확정되는 것은 아닙니다.**

## 각 팀원 제출 방법

1. `coordination/lecture-submissions/<과목-영문-slug>/note.md`를 하나 만듭니다. `TEMPLATE.md`를 복사해 사용합니다.
2. **2026-11-13 팀장 현장 지시**에 따라 PDF 원본도 `coordination/lecture-submissions/<과목-영문-slug>/pdfs/`에 넣고 비공개 팀 GitHub에 제출합니다. 강의자료를 공개 저장소·외부 링크에 배포하지 않습니다. 이전 `materials/` 별도 보관 정책과 충돌하므로 팀장이 공식 결정 문서에 변경을 반영해야 합니다.
3. PDF 파일명, 전체 페이지 수, SHA-256 해시를 적어 동일한 자료인지 확인할 수 있게 합니다.
4. 개념마다 **PDF 페이지(1부터 시작), 핵심 질문, 어떤 화면이 이해에 도움이 되는지, 그 근거**를 적습니다. 먼저 2~4개만 적어도 됩니다.
5. `확인됨 / 제안 / 미확인`을 구분해 적습니다. 예컨대 제안한 애니메이션이 현재 FE 플레이어에서 구현되는지까지 확정하지 않습니다.
6. 다른 사람의 노트는 고치지 않고 내 과목 폴더에 추가합니다. GitHub 문서 반영은 `AGENTS.md`와 D-31의 협업 규칙을 따릅니다.

**부품 예시:** `texts`(설명 글자), `codes`(코드), `grids`(표/격자), `diagrams`(도식), `slides`(원본 페이지 보여 주기), `actions`(강조·전환). 구현 가능 부품과 속성은 `docs/04-video-blueprint.md`와 실제 검사기를 확인해야 합니다.
