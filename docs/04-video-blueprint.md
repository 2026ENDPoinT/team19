# 04. 영상 설계도 방식

> 상태: 방향 합의 (D-05), 세부 미정 · 담당: AI (형식 초안), FE (재생) · 최종 수정: 2026-11-06 · AI/Claude

강현이 더 자세한 설명을 요청할 예정이다. 이 문서는 지금까지 이야기한 수준만 담는다.

## 한 줄 요약

AI가 영상을 직접 만들지 않는다. AI는 **설계도(장면 목록)**를 쓰고, 브라우저가 그 설계도대로 화면을 그린다.

## 왜 이 방식인가

| 방식 | 장점 | 문제 |
|---|---|---|
| 영상, 이미지 생성 AI | 화려하다 | 숫자, 수식, 글자가 뭉개지거나 틀린다. 비싸고 느리다. |
| Manim 같은 도구로 영상 파일 렌더링 | 3Blue1Brown 스타일을 낼 수 있다 | 클립마다 렌더링 시간이 길다. AI가 그 코드를 직접 짜면 오류가 잦다. |
| **설계도 + 브라우저에서 그리기** | 숫자와 그래프가 정확하다. 텍스트만 생성하므로 싸고 빠르다. 장면 하나만 고치기 쉽다. 반복 재생과 일시정지가 자연스럽다. | 화면 부품을 우리가 직접 만들어야 한다(FE 작업량). |

## 설계도에 들어가는 것 (개념)

- 클립 하나는 **장면** 여러 개로 이루어진다.
- 장면 하나에는 다음이 들어간다.
  - 내레이션 문장 (음성과 자막이 된다)
  - 화면에 놓을 **부품**
  - 부품의 **동작 순서** (몇 번째 문장에서 무엇이 움직이는지)
  - 근거 페이지 번호

## 부품 후보

1단계에 전부 만들지 않는다. 표시한 것부터 시작하자는 제안이다(Q-AI-09).

| 부품 | 쓰임 | 1단계 후보 |
|---|---|---|
| 제목, 텍스트 | 개념 이름, 핵심 문장 | ✓ |
| 수식 | 점화식, 공식 | ✓ |
| 숫자 배열 (칸) | 정렬, 탐색 과정 | ✓ |
| 포인터, 화살표 | 인덱스, 피벗, 이동 방향 | ✓ |
| 원본 슬라이드 조각 | 강의자료 그림 일부를 띄우고 강조 박스 | ✓ |
| 노드와 간선 그래프 | 그래프 알고리즘, 네트워크 구조 | |
| 트리 | 재귀 호출, 분할 과정 | |
| 상자와 화살표 다이어그램 | 소프트웨어공학 구조, 계층 | |
| 순서도, 메시지 흐름 | 프로토콜(예: TCP 연결 과정) | |
| 표 | 비교, 복잡도 | |
| 코드 | 의사코드, 줄 강조 | |

## 동작 후보

나타나기, 사라지기, 이동, 강조(색, 테두리), 값 바꾸기, 두 칸 교환, 화살표 연결, 코드 줄 강조

## 예시 스케치 (말로 설명)

**퀵정렬 분할 한 장면**
화면에 숫자 배열 8칸이 있다. "마지막 원소 5를 피벗으로 잡아요"라는 문장이 나올 때 5가 강조된다. "i는 왼쪽 밖에서 시작해요"에서 i 포인터가 나타난다. "j가 이동하면서 피벗보다 작은 값을 찾아요"에서 j가 한 칸씩 이동하고, 작은 값을 만나면 i가 한 칸 오고 두 칸이 교환된다. 마지막 문장 "j가 피벗 바로 앞까지 오면 끝나요"에서 종료 조건 문구가 강조된다.

**네트워크 한 장면 (코드가 없는 과목)**
왼쪽에 클라이언트, 오른쪽에 서버 상자가 있다. 문장에 맞춰 SYN, SYN-ACK, ACK 화살표가 차례로 그려지고, 각 단계에서 양쪽 상태 이름이 바뀐다.

## 음성과 맞추는 방법 (초안)

- 내레이션을 문장 단위로 나눈다.
- 각 동작은 "몇 번째 문장이 시작될 때" 실행한다.
- 음성을 만든 뒤 문장별 길이를 재서 장면 길이를 정한다. 그래서 클립 길이가 내용에 따라 달라진다(D-02).

## 화면 스타일

- 어두운 테마: 검정 배경, 수식과 숫자 중심
- 밝은 테마: 흰 배경, 그래프와 다이어그램 중심
- 하나만 할지, AI가 고를지, 사용자가 고를지는 미정이다(Q-AI-06).

## 알려진 위험

- **AI가 알고리즘 과정을 틀리게 계산할 수 있다.** 예: 정렬 중간 상태를 잘못 씀. 대책 후보는 배열 상태가 단계마다 앞뒤가 맞는지 검사하는 것이다. 자주 나오는 알고리즘은 실제 코드로 과정을 계산해서 넣는 방법도 있다(2단계 이후).
- **부품이 많을수록 FE 작업량이 커진다.** 1단계는 5~6개로 제한한다.
- **설계도 형식이 너무 복잡하면 AI 출력이 불안정해진다.** Claude의 구조화된 출력 기능은 재귀 구조를 지원하지 않고, 선택 항목과 여러 타입을 허용하는 항목의 개수에도 제한이 있다. 형식을 평평하고 단순하게 만든다.
