# 06. 비용과 예산

> 상태: 추정 + 일부 실측 · 담당: AI (팀장) · 최종 수정: 2026-11-12 · AI/Claude

## 확인한 가격 (2026년 11월 기준)

| 항목 | 가격 | 출처 |
|---|---|---|
| Claude Sonnet 5.5 | 입력 100만 토큰당 $2, 출력 100만 토큰당 $10 | Claude 가격 문서 |
| Claude Haiku 5.5 | 한 요청의 입력이 10만 토큰 이하면 입력 $0.10, 출력 $0.50. 넘으면 $0.50 / $2.50 (5배) | Claude 가격 문서 |
| 일괄 처리(Batch) | 위 가격의 50% 할인. 결과가 늦게 와도 되는 작업에만 | Claude 가격 문서 |
| 토크나이저 | 최신 모델은 같은 글을 이전보다 약 30% 많은 토큰으로 센다 | Claude 가격 문서 |
| PDF 페이지 | 페이지당 글자 1,500~3,000 토큰, 페이지 그림 비용 별도 | Claude PDF 문서 |
| TTS (OpenAI gpt-4o-mini-tts) | 1분에 약 1.5센트 | OpenAI 발표 기사 |

## 다른 회사 가격 (2026-11-07 공식 페이지 확인, 100만 토큰당 입력 / 출력)

| 등급 | Anthropic | OpenAI | Google | 강의 1개 (아래 추정 기준) |
|---|---|---|---|---|
| 상위 | Sonnet 5.5 $2 / $10 | GPT-6.1 Sol $2 / $10 | Gemini 4 Argon $2 / $10 (12/1부터 2배) | 약 $1.5 |
| 중간 | (없음) | GPT-6.1 Terra $1 / $5 | Gemini 3.8 Flash $0.75 / $3.75 | 약 $0.55~0.75 |
| 저가 | Haiku 5.5 $0.10 / $0.50 | GPT-6 Luna $0.10 / $0.50 | Gemini 3.1 Flash-Lite $0.25 / $1.50 | 약 $0.07~0.2 |

- 페이지 그림: 1280×720 한 장에 약 1,200토큰. 40쪽 전체를 그림으로 보내도 상위 등급 약 $0.1이다.
- GPT-6 Luna는 27.2만 토큰까지 같은 가격이다(Haiku 5.5는 10만 토큰).
- Gemini Flash 계열은 무료 구간이 있지만 데이터가 학습에 쓰일 수 있다. 공개 자료로만 실험한다.
- TTS는 대부분 1분에 1~2센트다(OpenAI gpt-4o-mini-tts 음성 출력 100만 토큰당 $12, Gemini 3.8 Flash TTS 약 1.4센트/분). 한국어 음질로 고른다(Q-AI-10).
- 성능은 같은 등급끼리도 우리 작업에서 직접 비교해야 한다(Q-AI-07 실험).

## 실험 예산 (Q-AI-07)

| 실험 | 내용 | 예상 비용 |

OpenAI와 Anthropic에 회사당 $5~10을 충전하면 충분하다(Q-AI-13). 팀에 구독 크레딧을 받을 수 있는 요금제(ChatGPT Pro, Claude Max 등)는 없다.

## 추정: 40쪽 강의, 클립 15개, Sonnet 5.5 기준

| 단계 | 계산 | 비용 |
|---|---|---|
| 분석, 분할 계획 | 입력 약 10만 토큰, 출력 약 8천 토큰 | 약 $0.3 |
| 클립 설계도 15개 | 클립당 입력 약 1.5만, 출력 약 5천 | 약 $1.2 |
| 음성 | 클립당 약 50초 × 15개 = 12.5분 | 약 $0.2 |
| **합계** | | **약 $1.5~2** |

- 시험 대비 모드로 클립이 30개면 약 $3 안팎이다.
- 실제 알고리즘 강의는 70~80쪽이다. 분석 입력이 약 2배가 되지만, 비용은 주로 클립 수로 정해진다. 거의 같은 슬라이드(애니메이션 단계)를 합치면 입력이 줄어든다. 80쪽이면 한 요청이 10만 토큰을 넘기 쉬워서 Haiku 5.5는 나눠 보내야 한다.
- 같은 작업을 Haiku 5.5로 하면 AI 부분이 약 1/20이 된다. 대신 분석 요청의 입력이 10만 토큰을 넘지 않게 나눠서 보내야 한다. 넘으면 그 요청 전체가 5배 가격이다.
- **모두 추정치다.** 실측은 아래 "실측"에 범위로 적는다.

## 실측 (범위로 기록한다)

설계도 비용은 클립 내용과 모델이 쓰는 출력 길이에 따라 **실행할 때마다 달라진다.** 같은 클립 1을 Sonnet으로 세 번 만들었더니 출력이 9.5천~21.5천 토큰, 비용이 $0.12~0.24로 두 배 차이가 났다. 그래서 한 숫자로 적지 않는다.

- **기록:** 명령줄로 돌린 유료 호출은 모두 `sandbox/ai/cost-log.jsonl`에 한 줄씩 쌓인다(`pipeline/costlog.py`). 서버에서 부를 때는 BE가 Job에 usage를 저장한다.
- **요약:** `py sandbox/ai/cost_summary.py`가 모델·단계별 횟수, 비용, 토큰 범위와 중앙값을 표로 낸다. 아래 표는 이 출력을 옮긴 것이다.
- **갱신 시점:** 평가 세트(P-AI-03)를 돌릴 때마다 고친다. 클립 하나가 아니라 여러 과목에서 잰 범위가 기준이다.
- **비교 단위:** 설계도는 1회 비용과 출력 토큰, 음성은 1분당 비용(약 $0.015)으로 비교한다. 클립 길이가 다르면 클립당 비용은 비교하기 어렵다.

2026-11-10 기준, 클립 1(합병 과정)만 잰 값:

| 단계 | 모델 | 횟수 | 1회 비용 | 입력 토큰 | 출력 토큰 |
|---|---|---|---|---|---|
| 설계도 | Claude Sonnet 5.5 | 3 | $0.115 ~ $0.237 (중앙 $0.150) | 8.2k ~ 9.1k | 9.5k ~ 21.5k |
| 설계도 | GPT-6.1 Terra | 3 | $0.020 ~ $0.022 (중앙 $0.021) | 5.3k ~ 5.8k | 3.0k ~ 3.4k |
| 음성 | gpt-4o-mini-tts | 3 | 새로 만든 음성 1분당 약 $0.015 | - | - |

- Terra는 Sonnet의 약 1/7 가격이고 실행마다 비용이 거의 같다. 품질 차이가 크지 않으면 Terra로 고정하는 방향이다(Q-AI-07). Haiku 5.5(Terra의 약 1/10 가격)도 평가 세트에서 비교한다.
- 이 기준이면 40쪽 강의, 클립 15개의 설계도는 Terra로 약 $0.3, 음성은 클립당 1~2분이면 약 $0.2~0.45다.

2026-11-12, 강의 5개(228쪽) 해설·분할과 다른 과목 클립 5개로 잰 값([실험 기록](../sandbox/ai/2026-11-12-mode-split-test.md)):

| 단계 | 모델 | 횟수 | 1회 비용 | 비고 |
|---|---|---|---|---|
| 페이지 해설 | GPT-6.1 Terra | 44 (6쪽씩) | $0.007 ~ $0.020 | 쪽당 약 $0.0025. 57쪽 강의 약 $0.14 |
| 분할 계획 | GPT-6.1 Terra | 15 | $0.011 ~ $0.035 | 모드마다 한 번 |
| 설계도 | GPT-6.1 Terra | 5 | $0.024 ~ $0.043 | speech 칸 포함, 20~25문장 |
| 설계도 | Claude Haiku 5.5 | 7 | $0.011 ~ $0.017 | 생각(effort high)이 출력 상한까지 차서 잘림이 잦다 |
| 음성 | gpt-4o-mini-tts | 5 | $0.015 ~ $0.032 | 88~107초 |

- 57쪽 강의 하나: review(클립 10개) 약 **$0.65**, exam(16개) 약 **$0.95**. 목표 "$1 미만" 안이다.

## 예산

- 해커톤 측 API 크레딧 지원은 없다. 팀 사비로 낸다.
- 예산은 5~10만 원 정도로 생각 중이다(팀 논의 필요, Q-AI-13). 대략 수십 달러이므로, Sonnet으로 강의 전체를 수십 번 생성할 수 있는 양이다.
- **진짜 위험은 개발 중 반복 호출이다.** 아래 절약 규칙을 지킨다.

## 비용 목표 (팀장)

- 강의 하나 전체 생성(모드 1개): **$1 미만**
- 개발 중 실험 한 번: **$0.1 미만**

80쪽, 클립 25개를 상위 등급으로 그대로 만들면 약 $2.2로 추정된다(설계도 약 $1.25, 페이지 해설 약 $0.45, 음성 약 $0.35, 분할 계획 약 $0.2). 아래 방법으로 약 $0.5~0.8을 목표로 한다. 모두 추정이라 실험에서 확인한다.

1. **설계도 형식의 군더더기 줄이기.** 배치, 색, 좌표는 플레이어가 정하고, AI는 의미 단위 동작(예: 두 칸 교환)만 쓴다. 중간 상태는 코드가 계산한다. **내레이션, 장면 수, AI의 생각 과정은 줄이지 않는다.** 필드 이름은 짧되 뜻이 보이게 한다.
2. 설계도는 중간 등급 모델 후보(GPT-6.1 Terra 등). 분할 계획처럼 품질이 가장 중요하고 비용이 작은 단계는 상위 등급을 쓴다.
3. 거의 같은 페이지(애니메이션 단계 슬라이드)를 합친다.
4. 같은 강의 내용을 여러 요청에 쓸 때 프롬프트 캐싱을 쓴다.
5. TTS는 한국어 음질이 버티면 싼 서비스를 쓴다.

## 절약 규칙 (개발 중)

1. FE와 BE는 저장된 샘플 결과로 개발한다. 진짜 AI를 부르지 않는다.
2. 단계별 결과(추출, 해설, 분할 계획, 설계도, 음성)를 파일로 저장한다. 프롬프트를 고칠 때는 그 단계만 다시 돌린다.
3. 프롬프트 실험은 챕터 하나(10~15쪽)와 클립 2~3개로 한다. 강의 전체 생성은 중요한 확인 때만 한다.
4. 개발 중 음성은 브라우저 내장 음성 읽기로 대신하고, 진짜 TTS는 시연용 결과에만 쓴다.
5. 급하지 않은 비교 실험은 Batch(50% 할인)로 돌린다.
6. 모델은 실험(Q-AI-07)으로 정한다. 싼 모델로 다듬은 프롬프트가 다른 모델에서도 같게 동작한다고 가정하지 않는다.
7. 콘솔에서 회사마다 월 지출 한도를 걸고(예: $10), 호출마다 입력, 출력 토큰 수와 비용을 기록한다.

## API 키 관리

- 키를 누구 명의로 만들지(팀장 1개 공용 또는 각자), 비용을 어떻게 나눌지 정한다(Q-AI-13).
- 키는 `.env` 파일에만 두고 GitHub에 올리지 않는다. 공유는 메신저로 한다.
- 키는 서버에서만 쓴다. 브라우저 코드에 넣지 않는다.

## 확인해 볼 것

- Claude 유료 구독 중 일부 요금제(Max, Team 등)는 매달 API 크레딧이 포함될 수 있다. 우리 팀에 해당되는지 문서를 확인한다: [API credits for subscribers](https://platform.claude.com/docs/en/about-claude/api-credits-for-subscribers)
- TTS는 다른 서비스와 한국어 품질, 가격을 비교해야 한다(Q-AI-10).
- Remotion을 쓰게 되면: 개인과 3명 이하 팀은 무료다. 우리 팀은 3명이라 무료 범위지만, 외부 협업자가 늘어 4명 이상이 되면 유료다.
