# 01. 제품 정의

> 상태: 확정 (해커톤 제출 기준) · 담당: 전원 (정리: AI) · 최종 수정: 2026-11-14 · AI/Claude

## 한 줄 정의

**EIDOS(에이도스, D-65)**: 강의 PDF를 올리면 학습 단계에 맞춰 개념과 예시 단위로 나눈 세로 숏폼 영상 시리즈를 만들어 주고, 쇼츠처럼 넘겨 볼 수 있는 웹 서비스.

## 왜 만드나 (강현 노트)

- 우리는 개념과 예시 단위로 이해한다. 그런데 강의 내용은 연속적이고 양이 많아서 버겁고 막막하다. 롱폼을 피하는 현상은 공부에서도 똑같다.
- 그래서 가볍게 볼 수 있는 개념 숏폼이 필요하다.
- 기준은 유튜브의 일반 영상이 아니라 **내 수업의 강의자료**여야 한다. 시험은 결국 강의자료, 수업 필기, 기출에서 나오기 때문이다.
- 기존 요약형 AI(UnivAI, Gpai 등)는 글 요약이다. 강의자료의 개념을 영상으로 하나씩 설명해 주는 서비스는 드물다. 비교는 [02-competition.md](02-competition.md)에 있다.

## 사용 흐름 (구현됨)

1. 강의 PDF를 올린다(100쪽까지, D-67). 업로드 화면에 "올린 자료는 외부 AI 서비스로 전송된다"는 고지가 있다(D-23).
2. 학습 모드를 고른다: **입문 / 기본 / 심화**(D-57, [05](05-segmentation-and-modes.md)).
3. AI가 자료를 분석해 클립 목록을 보여 주고, 클립 전체를 자동으로 만든다. 완성된 것부터 바로 재생할 수 있다(D-19). 실패한 클립은 그 클립만 다시 만든다.
4. 쇼츠처럼 위아래로 넘겨 보고 반복 재생한다. 버튼을 누르면 옆 패널에 지금 장면의 원본 페이지가 뜬다(D-30).
5. **내 강의함**: 로그인 없이 브라우저마다 만든 기기 ID로 내가 올린 강의만 다시 본다(D-50). 빼기는 진짜 삭제다(D-64).

## 영상이 갖춰야 할 것 (강현 노트)

- 세로 비율이다. 클립 길이 목표는 1~2분, 상한 120초(D-41). 입문은 40~70초.
- 예시는 시각화로 설명한다. 간단한 도형이나 강의자료의 그림을 쓰고, 화살표를 움직이거나 강조 표시를 한다.
- 알고리즘처럼 과정이 있는 내용은 정지 그림보다 움직임으로 보여준다. 배열이 어떻게 바뀌는지, 숫자가 어떻게 이동하는지, 피벗이 어떻게 움직이는지를 보여주고, **헷갈리는 종료 조건을 언제 만족하는지까지** 포함한다.
- 강의자료를 그대로 옮기지 않는다. AI의 사전 지식으로 보충 설명을 한다.
- 너무 압축하지 않는다. "당연히 이해했겠지" 하고 건너뛰는 것이 가장 나쁜 실패다.
- 별로 중요하지 않은 것은 굳이 넣지 않는다. 다만 무엇이 중요한지는 모드에 따라 다르다.
- 분량이 많으면 개념 영상과 예시 영상을 나눈다(예시 클립 제목은 "예시: "로 시작).
- 화면은 쌓여 가게 연출한다(D-56). 화면의 주인공은 크게 하나(D-59).

## 대상 자료 (D-18)

- 처리 구조는 과목에 상관없이 만들고, 품질 확인과 시연은 잘 되는 자료 몇 개로 한다. 모든 과목의 품질을 보장한다고 안내하지 않는다.
- 스캔 PDF는 보장 범위에서 뺀다. 손글씨 필기는 설명의 근거로 쓰지 않는다(D-24).
- 개발 기준 자료는 알고리즘 3강 분할정복이다. 이 자료에 맞춰서 만들지는 않았고, 그리디·소프트웨어공학·트랜스포머·강화학습·파이썬·경제의 이해로도 확인했다.

## 구현 범위 (D-04, 목표는 2단계까지)

| 단계 | 내용 | 상태 (11/14) |
|---|---|---|
| 1단계 (필수) | PDF 업로드 → 모드 선택 → 클립 여러 개 생성 → 세로 피드 재생과 원본 페이지 표시. 결과는 서버에 저장해서 새로고침해도 남는다 | 완료 |
| 2단계 (목표) | 내 강의함(지난 업로드 다시 보기) | 완료 (기기 ID, D-50) |
| 2단계 (목표) | 클립 저장, 요청을 적어서 클립 하나 다시 만들기 | 하지 않음 |
| 3단계 (여유) | 로그인, 앱 | 하지 않음 |

## 이번 범위에서 하지 않는 것

- 수업 필기와 기출 문제를 추가로 입력받는 기능(D-03), 시험 대비 문제 생성(D-42)
- 자체 AI 모델 학습(파인튜닝)
- 영상 파일(MP4) 내보내기. 웹 재생만 한다.
- 긴 PDF 자동 분할(D-67, 해커톤 뒤)
