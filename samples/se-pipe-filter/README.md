# 다른 과목 시각화 확인용: 파이프 앤 필터 (소프트웨어공학 21~22쪽)

> 상태: 화면 확인용 실제 결과 (Q-FE-07) · 담당: AI · 최종 수정: 2026-11-12 · AI/Claude

알고리즘이 아닌 과목(소프트웨어공학, 영어 굿노트 필기본)에서 AI 파이프라인이 만든 설계도다. 손으로 고치지 않았다. **음성과 자막 시간은 없다.** 화면만 먼저 확인한다(음성 싱크 확인과 구분).

## 파일

| 파일 | 내용 |
|---|---|
| `blueprint.json` | 설계도. 형식 v0, `pipeline/validate.py` 통과 |
| `plan.json` | 클립 계획 (`sourcePages` 21, 22) |
| `pages.json` | 설계도 생성에 넣은 페이지 글자와 페이지 해설(`description`) |
| `pages/page-021.png`, `page-022.png` | 원본 페이지 그림 (긴 변 1600px). 옆 패널과 slides에 쓴다 |

## [to:FE] 확인 방법

- 장면 5개, 20문장, 예상 약 80초(글자 수로 추정). 부품: texts, diagrams(row), codes, **slides(22쪽 흐름도 + `mark` 9번)**.
- clip-01과 달리 **slides를 쓴다.** s4는 22쪽 그림을 `box` [0.11, 0.35, 0.78, 0.42]로 잘라 보여 주고, 문장마다 상자에 `mark`(라벨 포함)를 붙였다 뗀다. mark 위치가 그림의 상자와 맞는지가 핵심 확인 항목이다.
- 음성이 없으니 문장을 수동으로 넘기거나, 문장당 4초처럼 임의 시간을 줘서 넘겨 보면 된다. 임의 시간은 확인용이고 계약이 아니다.
- 볼 것: row 다이어그램에 `|` 같은 짧은 라벨, 2줄 셸 코드의 `markLine`, `setText`로 제목 바꾸기(s3), `hidden` 부품의 `show`(s1 코드, s3·s5 키워드), slides 안 `mark` 라벨이 겹치지 않는지.

## 알려진 점

- 22쪽은 글자가 제목뿐이라 **페이지 해설(`description`)은 AI/Claude가 그림을 보고 직접 썼다.** 파이프라인의 페이지 해설 단계는 아직 없다(Q-AI-07). 상자 좌표도 해설에 적어 줬다.
- 21쪽 손글씨 필기는 근거로 쓰지 않았다(Q-AI-23).
- 자막에 "캣", "그렙", "더블유 씨"처럼 명령어를 한글로 적었다. 자막과 음성 원고를 나누는 P-AI-04가 다룰 문제다.
- 클립 하나의 결과라 설계 품질 평가(P-AI-03)는 아니다.
