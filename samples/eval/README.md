## [to:FE] 재생 방법

- **`result-terra.json` + `audio-terra/audio.mp3`가 한 묶음이다.** `result-terra.json`은 ClipResult 모양(설계도 + captions + durationSec)이고, `audioUrl`은 이 폴더 기준 상대 경로다. 다른 폴더의 음성과 섞지 않는다.
- `pages/`는 원본 페이지 그림(옆 패널, slides용), `pages.json`은 설계도를 만들 때 넣은 글자와 페이지 해설, `plan.json`은 클립 계획이다.
- 설계도 장면에 **`speech` 칸**이 있다(P-AI-04, 음성 원고). 자막은 지금처럼 `captions.text`(= `lines`)를 쓰면 된다. FE는 `speech`를 무시해도 된다(P-AI-04 FE 확인과 같음).
- `blueprint-haiku.json`은 모델 비교용이다. 음성이 없어 화면만 볼 수 있다. 알고리즘은 Haiku가 실패해서 없다.
